## REQ-50 — The administrator is able to review all custom wholesale app...
- **Status:** ✅ RESOLVED
- **Question:** [NEEDS CLARIFICATION] The requirement "The administrator is able to review all custom wholesale application data (Type ..." is ambiguous. Please specify: What exactly is expected? What are the specific acceptance criteria?
- **Resolution:** After a customer submits the registration form, a notification email is sent to the admin. The admin reviews and activates the account via the nopCommerce Admin panel: Customers → Customers, using the "Active" filter dropdown set to "All" to list all customers regardless of status. Newly registered customers appear in the grid with Active = No (inactive). The admin opens the first such record, sets it to Active, and saves — this activates the account and allows the customer to log in to the storefront.
